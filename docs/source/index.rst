Welcome to AdsNet's documentation!
===================================

AdsNet (Adsorption Network) is a graph neural network potential framework for predicting adsorption energies on metal surfaces. It implements a PaiNN-style equivariant message-passing architecture with scalar and vector node features, focusing on adsorbate–surface systems.

The code is available and actively maintained on `GitHub <https://github.com/changzhiai/AdsNet>`_. Users are encouraged to explore the repository for asking questions, or reporting issues.
